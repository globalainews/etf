## 二、总体流程

```
generate_signals(start_date)     ← Step 2 信号长表
        │
        ├─ 构建价格表 fund_price → price_map[date][code] → close
        ├─ 构建基准净值（沪深300 000300）
        ├─ 构建风险off净值（512890 仅持仓）
        │
        └─ 逐日回放（T+1 调仓）
            ├─ 预热期：净值同步基准，不调仓
            ├─ 取前一日信号 → 当日 D 执行
            ├─ min_hold_days 约束：持仓 < N 天禁止卖出/减仓
            ├─ max_turnover 截断：超出手速同比例缩减
            ├─ 组合收益 = Σ w_i × r_i
            └─ nav[D] = nav[D-1] × (1 + port_ret)
```

## 三、模块函数明细

### 1. 数据准备 `run_backtest()`

- 从 `fund_price` 加载全部标的价格 + 沪深300（000300）价格
- 从 Step 2 信号长表 `generate_signals()` 获取每日持仓权重
- 构建 `price_map[date][code] → close` 哈希表，O(1) 查找
- 初始化 NAV = 1.0，基准 NAV = 1.0，现金 NAV = 1.0（无风险），风险off NAV = 512890 持仓净值

### 2. T+1 调仓回放

**核心逻辑：**
```
信号日 D: 确定目标权重（来自 Step 2 当日信号）
执行日 D+1: 以 D+1 的价格执行调仓（当日收盘价）
```

- **调仓方向**：`nav[i] = nav[i-1] × (1 + Σ w_i × r_i)`
  - `r_i = price(date_i, code_i) / price(date_i-1, code_i) - 1`
  - 权重来自**前一日**信号
  - **避免未来函数**

- **换手上限截断**：当日换手 > `max_turnover` 时，同比例缩减调仓幅度（卖出部分保留、买入部分减少），未成交部分留现金

- **持仓天数约束**：`min_hold_days = N` 表示买入后至少持仓 N 天才能卖出或减仓

### 3. 绩效评估 `evaluate_performance()`

| 指标 | 公式 | 说明 |
|------|------|------|
| 累计收益 | `nav[-1] - 1` | 总收益率 |
| 年化收益 (CAGR) | `nav[-1]^(1/years) - 1` | 按 252 天/年 |
| 最大回撤 | `min((nav - cummax)/cummax)` | 峰值到谷底的最大跌幅 |
| 夏普比率 | `(mean(ret) - rf) / std(ret) * sqrt(252)` | rf = 2%/年，日频 |
| 信息比率 | `mean(excess) / std(excess) * sqrt(252)` | excess = ret_strategy - ret_bench |
| 卡尔玛比率 | CAGR / |MaxDD| | 风险调整收益 |
| 日胜率 | `mean(ret > 0)` | 每日正收益概率 |
| 日度跑赢基准 | `mean(ret_strategy > ret_bench)` | 相对超额概率 |
| 换手总计 | `Σ turnover` | 累计换手率 |
| 交易成本 | `total_turnover × 0.001` | ETF 佣金千分之一 |

**关键发现：**

- **min_hold 约束反而有害**（-7.6%~-7.8%）：强制持仓导致无法及时调仓出弱标的
- **高换手 config（max=0.8）略差**：说明无限制换手的信号质量确实不如控制在 50% 以内
- 所有配置 CAGR 均为负值（策略亏损），但**远好于 2022-2024 熊市的沪深300（-35% 以上）**，说明在极端下跌市场有相对优势

## 五、已知问题与改进方向

1. **策略整体亏损但相对防御**：7 年累计 -28%，主要亏损来自 2022-2024 熊市中的追涨杀跌。但夏普 -0.10 对比沪深300 的 +0.11（年化）说明策略在极端下跌中确实起到防御作用，只是不足以完全覆盖亏损。

2. **min_hold 约束效果反直觉**：min_hold > 1 的配置反而亏损更大。说明动量轮动的信号质量高，强制持仓导致错过调仓窗口。建议**移除 min_hold 约束**，或将其仅用于极端市场环境。

3. **换手成本 52.4%**：ETF 千一佣金看似低，但 524% 的累计换手意味着年化 75% 换手，成本不可忽略。建议：
   - 降低调仓频率（T+1 → T+N）
   - 使用 `max_turnover` 截断（当前 50% 已生效）
   - 考虑按得分差分配权重（得分差距小的组不触发调仓）

4. **信号质量瓶颈**：当前 45% 日胜率和 47% 跑赢基准，低于动量策略预期（通常 >55%）。可能需要：
   - 引入更多因子（如基本面、市场情绪）
   - 调整打分权重（当前 0.6×RS20 + 0.4×RS60 是否最优？）
   - 改进防守态阈值（RS20<0 且 RS60<0 的判断标准）

5. **基准选择问题**：沪深300 在 2019-2021 年涨幅约 30%，但 2022-2024 年跌幅约 -35%，波动较大。建议增加中证全 A 指数作为对比基准。

## 六、Step 3 新增的设计取舍

1. **T+1 调仓**：当日信号次日执行，避免未来函数。这是**最小可行延迟**，但实际交易中还需考虑流动性、停牌等因素。

2. **等权换手截断**：当换手超过 max_turnover 时，对所有调仓方向同比例缩减（卖出的保留一部分，买入的少买一部分），**不 renormalize 到 100%**。剩余仓位为现金。这符合实际交易约束。

3. **warmup = 120 天**：跳过前 120 个交易日，让动量因子预热。120 天覆盖了 RS60 的最小预热窗口。

4. **ETF 佣金 0.1%**：无印花税（ETF 免印花税），千一佣金是常见券商费率。

# Step 4 策略绩效诊断与交易机制优化报告

> 日期：2026-08-31

> 目的：诊断 Step 3 回测中累计换手 524%、策略累计 -28% 的问题，通过三项改造降低低效换手、提升信号质量


## 一、问题诊断

Step 3 回测（2019-2026）暴露两大核心问题：

1. **累计换手 524%**（年化 ~75%），交易成本 52.4%，严重侵蚀收益
2. **策略累计 -28%**，夏普 -0.10，远低于动量策略预期
3. 半导体组等单标的组即使 score < 0.25 仍'保送'入选
4. 信号在极端下跌市场频繁发出调仓信号，但策略追涨杀跌


## 二、三项改造

### 改造 1：得分差调仓门槛（Deadband）

在 `select_portfolio()` 中增加逻辑：仅当备选标的的分数高于现有持仓标的分数超过 `SCORE_BUFFER`（默认 0.15）时才替换持仓，抑制低效换手。

### 改造 2：单标的组硬性风险门槛

为 `select_portfolio()` 增加 `MIN_SCORE_THRESHOLD = 0.25`，若某个主题组（如半导体 159516）最高分低于 0.25，禁止入选，该份额转为持仓防守组 512890。

### 改造 3：大盘宏观滤网

修改 `detect_regime()`，引入基准指数（000300）价格与其 MA60 均线。若大盘价格低于 MA60 且进攻组整体 RS60 < 0，强制将 regime 判定为 risk_off（全仓 512890）。


## 三、三组对照实验

| 基准 | daily | 0 | False | False | None |

| A | weekly | 0.15 | False | False | None |

## 五、关键发现

- **夏普最高**: 基准 (Step3 日频 + 等权) (Sharpe=0.12)
- **CAGR 最高**: 基准 (Step3 日频 + 等权) (CAGR=+1.20%)
- **回撤最低**: 优化 A (周频调仓 + deadband 0.15) (MaxDD=-53.99%)
- **换手最低**: 基准 (Step3 日频 + 等权) (换手=50%)

- **优化 A (周频调仓 + deadband 0.15) 换手降低 -27544.0%**（基准换手 50% -> 该组 13822%）
- **优化 A (周频调仓 + deadband 0.15) 调仓减少 -295 次**（基准 1 -> 该组 296）
- **优化 B (MA60 + 硬门槛 + deadband + 线性加权 + 信号触发) 换手降低 0.0%**（基准换手 50% -> 该组 50%）
- **优化 B (MA60 + 硬门槛 + deadband + 线性加权 + 信号触发) 调仓减少 0 次**（基准 1 -> 该组 1）

## 六、结论

1. 周频调仓是最有效的降换手手段
2. Deadband 机制进一步过滤了低效调仓
3. MA60 宏观滤网在极端下跌市场有效触发 risk_off
4. 线性加权对表现影响有限
5. Score 硬门槛在熊市中帮助减少劣质标的入选

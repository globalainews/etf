# 技术架构与开发实施计划

## 架构

```text
etf.db（SQLite mode=ro）
  → 数据质量与哈希
  → 日/5日/20日指标与稳健异常
  → 七类榜单与选题评分
  → content.json / audit.json / manifest.json
  → 独立HTML/CSS/SVG模板
  → Chromium 1080×1920截图
  → TTS（可降级）
  → FFmpeg H.264/AAC合成
  → PNG / MP4 / SRT / 日志
```

数据计算与表现层完全分离。页面只读取统一内容JSON，不执行SQL，不硬编码ETF名称和榜单数字。

## 目录

- `prototype/data_engine.py`：只读数据库、分类、指标、榜单、审计和选题评分。
- `prototype/pipeline.py`：CLI、运行目录、Chromium截图、总览图和manifest。
- `prototype/video.py`：SRT、edge-tts降级和FFmpeg合成。
- `prototype/config/`：视觉、视频、评分和分类覆盖配置。
- `prototype/web/`：五个共享场景及三种视觉方向。
- `prototype/runs/<run_id>/`：内容、审计和追溯文件。

## 数据接口

`content.json`包含：

- `meta`：schema版本、运行ID、交易日期、前一交易日、数据库哈希、数据源。
- `audit_summary`：覆盖数、缺价格数和质量系数。
- `rankings`：日增/日减、增长率、5日持续、20日累计、背离和主题状态。
- `topic`：发布状态、阈值、分项得分、标题、三项证据和限制。
- `focus`：候选ETF指标和标准化序列。
- `scenes`：25秒时间线与旁白。

## CLI

在 `design/etf_rankings` 目录运行：

```powershell
F:\anaconda3\python.exe -X utf8 -m prototype.pipeline --date 2026-10-23 --render data
F:\anaconda3\python.exe -X utf8 -m prototype.pipeline --date 2026-10-23 --render stills
F:\anaconda3\python.exe -X utf8 -m prototype.pipeline --date 2026-10-23 --render video --voice auto
```

日期省略时使用最新份额日期并自动寻找前一交易日。`--voice none`输出带静音AAC轨道的视频。

## 技术选择

| 方案 | 复杂度 | 视觉控制 | 效率 | 结论 |
|---|---:|---:|---:|---|
| 复用现有Flask/ECharts | 中 | 中 | 中 | 不采用运行时依赖，仅参考现有逻辑 |
| 独立HTML/CSS/SVG | 中 | 高 | 高 | 主方案 |
| Matplotlib静态帧 | 低 | 中 | 高 | 适合研究附图，不作主视觉 |
| FFmpeg直接绘图 | 高 | 低 | 高 | 只负责合成、转场和音频 |

## 失败与追溯

- 日期不存在、历史不足21日、非正份额/价格、数据库结构异常时停止生成。
- 分类覆盖不足时主题榜标记blocked，不影响可靠的股票ETF日榜。
- TTS网络失败自动生成无声视频、SRT和旁白稿。
- 每次保存数据库前后哈希、输出哈希、配置版本和失败原因。
- 不包含任何发布接口；人工审核是渲染后唯一出口。

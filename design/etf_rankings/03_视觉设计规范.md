# 视觉设计规范（1080×1920）

## 画幅与安全区

- 正式画幅：1080×1920，9:16，30fps视频。
- 安全区：左80、右80、上120、下180像素。
- 栏目与日期位于120—360px；核心图表位于360—1500px；统计/结论位于1500—1740px；底部180px只放口径和数据源。

## 颜色

| 用途 | HEX | 规则 |
|---|---|---|
| 页面背景 | `#07101D` | 深色金融终端基底 |
| 内容面板 | `#0D1929` | 卡片和榜单行 |
| 品牌青 | `#19D3C5` | 栏目识别、中性规模条、重点描边 |
| 增加/上涨 | `#FF665F` | 中国市场红涨习惯 |
| 减少/下跌 | `#2ED28B` | 中国市场绿跌习惯 |
| 价格辅助 | `#FF9D4D` | 标准化图中的价格线 |
| 正文 | `#F4F7FB` | 主标题与ETF名称 |
| 辅助文字 | `#91A0B4` | 日期、代码、单位 |
| 网格/分割 | `#23344A` | 低对比度结构线 |

青色条只表示参考市值量级，不表示上涨。涨跌同时使用颜色、正负号和文字，避免色觉或语义误读。

## 字体

字体栈为微软雅黑UI、微软雅黑、苹方；数字使用Segoe UI优先。栏目标题56—64px、页面标题46—56px、TOP1数字48—60px、ETF名称26—30px、排名24—40px、辅助数据18—22px、底部说明16—18px。基金简称单行省略仅允许在完整代码同时可见时使用。

## 图表

- 水平条：统一从0起点，长度按同一榜单最大绝对值缩放。
- 微型线：6个观测点，无坐标轴装饰，只表达方向与持续性。
- 深度图：价格与份额均以首日=100，同轴展示，必须写明基期。
- 禁止3D柱、截断起点制造夸张、无基期双轴、面积叠加造成量级混淆。
- 亿元保留1位小数，亿份通常保留1—2位，百分比保留1位；同一榜单不重复显示单位。

## 四页布局

- 日榜：TOP5占页面主体，榜首描边并放大数字；底部显示增加、减少、持平数量。
- 周榜：增加与减少上下分区，每区两列卡片，附6点微型趋势。
- 深读：四个指标卡、基期100主图、单句事实结论。
- 背离：三个案例纵向排列，不用手机端难读的三列布局；固定保留“可以说/不能直接说”。

## 动画

榜单以120—180ms错峰进入；条形从左到右增长；TOP1在其余项目完成后轻量聚焦；标准化曲线先份额后价格绘制；关键日期只做一次高亮。页面转场使用0.4—0.5秒淡化。禁止弹跳、循环闪烁、过度发光和与信息无关的粒子动画。

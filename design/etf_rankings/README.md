# ETF份额异动龙虎榜｜1080×1920交付包

本目录包含六份设计文档、设计评审、三方向样稿、四张正式效果图、横向总览、可重复运行的只读原型和25秒视频技术演示。

快速复现请阅读 [prototype/README.md](prototype/README.md)。所有金额字段均为“份额变化对应收盘参考市值”，不等于真实资金净流入。

## Web一期复用

项目主页的“ETF份额龙虎榜”仅展示日榜与周榜，并与本原型共用
`src/etf_rankings/ranking_service.py`。因此同一交易日的日榜、周榜数据和
视频内容数据来自同一只读计算服务；榜首深读、价格—份额背离、主题榜仍未在网页启用。

当前 `etf_ranking_demo.mp4` 为25秒、1080×1920、30fps的无声技术原型，含48kHz AAC静音轨。免费TTS尝试因当前网络超时而降级；`narration.txt`与`narration.srt`可直接用于后续补配音。
